🧪 Test Redirection 404

ℹ️ Objectif

Ce fichier teste si la redirection 404 fonctionne correctement pour les routes SPA.

⚠️ Problème actuel

La route /reset-password retourne une erreur 404 sur ciara.city.

🔗 Test 1 : Routes qui devraient fonctionner

Ces liens testent les routes principales :

Test page d'accueil (/) Test page d'authentification (/auth) Test page de profil (/profile)

🔗 Test 2 : Routes qui devraient rediriger via 404.html

Ces liens testent la redirection 404 :

Test reset-password sans paramètres Test reset-password avec paramètres Test auth/callback Test auth/error

🔗 Test 3 : Routes inexistantes

Ces liens testent des routes qui n'existent pas :

Test route inexistante Test route complexe inexistante

📋 Instructions de test

  1. Ouvrir http://localhost:8080/test-404-redirect.html
  2. Cliquer sur chaque lien de test
  3. Observer ce qui se passe
  4. Vérifier que les routes SPA fonctionnent

🎯 Résultat attendu

Après déploiement, toutes les routes devraient fonctionner ou rediriger correctement vers l'application SPA.

  • Logs de redirection 404.html
